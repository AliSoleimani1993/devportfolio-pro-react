# 🌐 Computer Networking Basics

## 1. What is a Network?
A network is two or more computers connected together to share resources.

## 2. OSI Model (7 Layers)
| Layer | Name | Function | Example |
|-------|------|----------|---------|
| 7 | Application | User Interface | HTTP, FTP, Email |
| 6 | Presentation | Data Format | SSL, Encryption |
| 5 | Session | Connection Management | Authentication |
| 4 | Transport | Data Transport | TCP, UDP |
| 3 | Network | Routing | IP, Routers |
| 2 | Data Link | Physical Addressing | MAC Address, Switches |
| 1 | Physical | Cables, Signals | Ethernet, WiFi |

## 3. TCP/IP Model (4 Layers)
- Application (HTTP, FTP, SMTP)
- Transport (TCP, UDP)
- Internet (IP)
- Network Access (Physical)
